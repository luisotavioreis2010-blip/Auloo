# Auloo

Plataforma educacional gratuita de matemática e ciências da natureza.

Cada aula tem três partes:
- **Explicação animada** — o conceito se monta na tela, passo a passo
- **Simulador interativo** — você mexe nas variáveis e vê o resultado em tempo real
- **Resumo e exercícios** — fixação do conteúdo

## Tecnologias

- HTML5 + CSS3 (vanilla)
- JavaScript (ES2020)
- Supabase (auth + database + storage)
- Deno Edge Functions
