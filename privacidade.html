Política de Privacidade

Última atualização: outubro de 2026

01

Quem somos

O Auloo é uma plataforma educacional online acessível em https://auloo.com.br. Permite que usuários criem contas e acessem um painel de estudos personalizado.

02

Quais dados coletamos

  • Dados de cadastro: nome completo e endereço de e-mail.
  • Dados de autenticação: senha criptografada e, opcionalmente, login via Google, GitHub ou Discord.
  • Foto de perfil: imagem enviada voluntariamente pelo usuário.
  • Dados de uso: informações básicas de acesso à plataforma (data, hora, dispositivo).
03

Como usamos seus dados

Seus dados são usados exclusivamente para:

  • Criar e gerenciar sua conta
  • Permitir login e autenticação segura
  • Personalizar sua experiência (nome, foto)
  • Enviar códigos de verificação por e-mail
  • Garantir a segurança da plataforma
04

Compartilhamento com terceiros

Utilizamos os seguintes serviços para operar o Auloo:

  • Supabase — armazenamento seguro de dados e autenticação
  • Resend — envio de e-mails de verificação
  • Cloudflare — hospedagem e proteção contra ataques
  • Google — opção de login social (quando escolhida pelo usuário)

Não vendemos, alugamos ou compartilhamos seus dados com terceiros para fins publicitários.

05

Seus direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (LGPD), você pode:

  • Acessar seus dados a qualquer momento
  • Corrigir informações incorretas
  • Solicitar a exclusão da sua conta e dados
  • Revogar consentimento
06

Segurança

Adotamos medidas técnicas como criptografia de senhas, HTTPS em todas as conexões e políticas de Row Level Security no banco de dados para proteger suas informações.

07

Contato

Para exercer seus direitos ou tirar dúvidas, envie um e-mail para: luisotavioreis2010@gmail.com
